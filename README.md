# Trading Signal Bot

Watches crypto pairs on an exchange and posts trading signals to Telegram.

> ⚠️ **Educational only — not financial advice.** Signals are generated by simple
> indicator rules and will lose often. Backtest before using, and never risk money you can't afford to lose.

## Strategy

| Rule | LONG | SHORT |
|---|---|---|
| Trigger | EMA 20 crosses **above** EMA 50 | EMA 20 crosses **below** EMA 50 |
| Filter | RSI between 50 and 70 | RSI between 30 and 50 |
| Stop-loss | entry − 1.5 × ATR | entry + 1.5 × ATR |
| Take-profit | 2R (2× the stop distance) | 2R |

Signals fire only on **closed** candles, and each one is sent once. All parameters live in `.env`.

## Setup

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # then edit it
```

Telegram:
1. Create a bot with [@BotFather](https://t.me/BotFather) and copy the token into `TELEGRAM_BOT_TOKEN`.
2. Add the bot as an admin of your channel and set `TELEGRAM_CHAT_ID=@yourchannel`.

## Usage

```bash
# Backtest a pair first (ignores fees/slippage, so real results are worse)
python -m signal_bot.backtest BTC/USDT --limit 1000

# Run the bot (DRY_RUN=true prints signals instead of sending)
python -m signal_bot.main

# Tests
pytest
```

## Layout

```
signal_bot/
  config.py      # loads .env
  indicators.py  # EMA, RSI, ATR
  strategy.py    # signal rules + SL/TP
  exchange.py    # OHLCV data via ccxt (no API key needed)
  telegram.py    # message format + sending
  main.py        # polling loop
  backtest.py    # historical test
tests/
```
